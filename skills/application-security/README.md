# Application security

Skills for designing, building and testing software securely: threat
modelling, security requirements, secure design review, and verification.

- **[threat-model-guardrails](./threat-model-guardrails/SKILL.md)**: Turn a
  product or feature specification into an attack-surface inventory, a STRIDE
  threat model, a guardrail catalogue with enforcement strengths, and testable
  security requirements that test-writing agents must cover. Model-invoked
  when a spec is shared with a security ask, or invoked by name.
